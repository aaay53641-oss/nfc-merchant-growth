### 1.2 活动首页

#### 页面结构

```
┌─────────────────────────────────────┐
│  顶部导航栏                          │
│  [门店logo] 门店名称    [我的奖励]   │
├─────────────────────────────────────┤
│  Banner轮播区                       │
│  活动宣传图(可配置多张)              │
├─────────────────────────────────────┤
│  NFC碰卡引导区                      │
│  ┌─────────┐                        │
│  │  NFC    │  "碰一碰 开启寻宝之旅"  │
│  │  图标   │  [立即碰卡]             │
│  └─────────┘                        │
├─────────────────────────────────────┤
│  三关进度展示区                      │
│  第一关 [●] 第二关 [○] 第三关 [○]    │
│  "已解锁"  "未解锁"  "未解锁"       │
├─────────────────────────────────────┤
│  快捷入口                           │
│  [我的任务] [奖励中心] [异业券]      │
└─────────────────────────────────────┘
```

#### 字段说明

| 字段名称 | 类型 | 说明 |
|----------|------|------|
| storeLogo | String | 门店logo图片URL |
| storeName | String | 门店名称 |
| bannerList | Array | 轮播图列表，每项含imageUrl、linkUrl |
| nfcGuideText | String | NFC引导文案 |
| nfcButtonText | String | NFC按钮文案，默认"立即碰卡" |
| gateProgress | Object | 三关进度 {gate1: boolean, gate2: boolean, gate3: boolean} |
| gateLabels | Array | 三关标签文案 |

#### 交互逻辑

1. 用户进入页面时，系统判断是否已碰过NFC
   - 已碰过：显示已解锁进度
   - 未碰过：显示NFC引导
2. 点击"立即碰卡"后，调起手机NFC功能
3. 碰触NFC桌贴后，系统记录碰卡记录，解锁第一关
4. 页面实时更新三关进度状态

## 7. 异常流程

### 7.1 任务超时

#### 场景描述
用户在任务有效期内未完成提交

#### 处理流程

```
1. 系统在任务创建时设置有效期(expireTime)
2. 任务到期前24小时推送提醒通知
3. 任务到期后自动变更状态为EXPIRED
4. 已过期的任务不可重新激活
5. 用户需重新参与活动获取新任务
```

#### 状态变更
AVAILABLE/PENDING_REVIEW -> EXPIRED

---

### 7.2 重复提交

#### 场景描述
用户对同一任务重复上传凭证

#### 处理流程

```
1. 用户提交凭证时，系统检查是否存在SUBMITTED或PENDING_REVIEW状态的任务
2. 如存在，提示"该任务已有待审核的提交，请等待审核结果"
3. 如审核被驳回，用户可重新提交
4. 系统记录每次提交的时间戳和内容hash
5. 完全相同内容的重复提交将被拦截
```

#### 状态变更
SUBMITTED -> SUBMITTED(重复检测拦截)

---

### 7.3 审核驳回

#### 场景描述
商家或平台审核用户凭证时发现不符合要求

#### 处理流程

```
1. 审核人员选择驳回原因(模板或自定义)
2. 驳回原因模板：
   - 图片不清晰，无法辨认
   - 非本店场景/内容
   - 任务要求不符
   - 疑似网络盗图
   - 重复提交
3. 系统通知用户审核结果及驳回原因
4. 用户可根据驳回原因修改后重新提交
5. 重新提交后进入新的审核流程
```

#### 状态变更
PENDING_REVIEW -> REJECTED

---

### 7.4 NFC碰卡失败

#### 场景描述
用户碰触NFC卡后系统未识别或记录

#### 处理流程

```
1. 用户碰卡后，手机端显示碰卡结果
2. 如碰卡失败，显示失败原因：
   - 手机不支持NFC
   - NFC功能未开启
   - 卡贴损坏
   - 网络异常
3. 用户可尝试重新碰卡
4. 商家可检查NFC卡状态
5. 如确认卡贴损坏，商家可申请更换
```

---

### 7.5 奖励库存不足

#### 场景描述
用户完成任务后，对应奖励库存为0

#### 处理流程

```
1. 用户完成任务，系统检测奖励库存
2. 如库存为0，提示用户"该奖励已发放完毕，请关注下次活动"
3. 商家收到库存不足提醒
4. 商家可联系平台补充库存
5. 补充库存后，新完成任务用户可正常领取
```

---

### 7.6 奖励核销异常

#### 场景描述
商家核销时出现异常情况

#### 处理流程

```
1. 商家扫码核销时，系统验证：
   - 奖励有效性
   - 奖励归属人
   - 使用门店范围
   - 有效期状态
2. 如验证失败，显示具体原因：
   - 奖励不存在
   - 奖励已被使用
   - 奖励不属于当前门店
   - 奖励已过期
3. 如遇系统异常，商家可记录并联系平台处理
4. 平台可人工介入处理核销争议
```

---

### 7.7 商家套餐到期

#### 场景描述
商家的收费套餐服务到期

#### 处理流程

```
1. 套餐到期前7天推送续费提醒
2. 套餐到期后：
   - 商家后台仅可查看数据，不可操作
   - 进行中的活动自动暂停
   - NFC卡功能暂停
   - 用户可继续领取已发放的奖励
3. 商家续费后，功能自动恢复
4. 超过30天未续费，商家数据归档
```

---

### 7.8 平台系统故障

#### 场景描述
平台系统出现故障影响正常业务流程

#### 处理流程

```
1. 系统监控自动检测异常
2. 关键业务进入保护模式：
   - 用户碰卡记录本地缓存
   - 凭证提交进入离线队列
   - 审核操作暂停
3. 故障恢复后：
   - 离线数据自动同步
   - 积压任务批量处理
   - 用户收到补偿通知
4. 商家可查看故障期间的运营数据
```
