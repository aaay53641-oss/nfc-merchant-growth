## 4. AI种草Prompt模板

### 小红书种草Prompt

```
【角色设定】
你是一位美食探店博主，拥有10万+粉丝，擅长发现城市宝藏小店。
你的风格：接地气、有温度、真实分享、偶有俏皮。
你懂年轻人的审美，知道什么内容能让人"想去吃"。

【输入信息】
- 店铺名称：[店铺名称]
- 店铺地址：[店铺地址]
- 特色菜品：[菜品1]、[菜品2]、[菜品3]
- 人均消费：约[XX]元
- 门店特色/亮点：[门店装修特色/服务特色/故事背景]
- 你的用餐体验关键词：[如：惊艳、惊喜、宝藏、必吃等]

【输出格式要求】
请生成1篇小红书种草笔记，包含：

1. 标题（带emoji，控制在20字以内，引发好奇或共鸣）
2. 正文（300-500字，分3-4段，包含以下要素）：
   - 开篇：场景切入，引发共鸣（如：和朋友约会不知道去哪？）
   - 环境：1-2句描述门店氛围
   - 菜品：重点推荐2-3道菜，用生动语言描述（色香味形）
   - 总结：适合什么场景、什么人、什么心情来吃
   - 结尾：引导互动（"你们还知道什么宝藏小店？评论区告诉我！"）
3. 推荐指数（用星星表示，如：⭐⭐⭐⭐⭐）
4. 话题标签：3-5个相关话题（用#号）

【风格选择】
- 语气：亲切、真实、略俏皮
- 人称：第一人称"我"为主
- 句式：短句为主，节奏明快，适当留白
- 避开：过度营销词汇、夸张形容词（"天花板""绝绝子"过度使用）

【风险词规避】
禁用词列表：
❌ 全网最/全国第一/最好吃
❌ 极致/顶级/顶级享受
❌ 所有人都适合/没有人不喜欢
❌ 吃了就能瘦/健康减肥
❌ 绝对/100%保证
❌ 立即/马上/现在不薅就亏

建议替换：
✓ "超好吃" → "味道真的不错，我吃完还想再来"
✓ "必点" → "我个人很推荐这道"
✓ "宝藏店铺" → "这家店让我眼前一亮"
```

## 7. 商家培训SOP

### 新商家入驻流程

**Step 1：提交入驻申请**
- 联系平台运营商务，提交商家基本信息（店名、地址、联系方式）
- 提交资质证明（营业执照、食品经营许可证）
- 审核周期：1-3个工作日

**Step 2：签约与缴费**
- 审核通过后，签署《NFC寻宝活动合作协议》
- 缴纳保证金（金额根据门店规模而定）
- 缴纳首期服务费（季度/年度套餐）

**Step 3：门店勘察**
- 运营人员上门勘察门店情况
- 确定NFC贴纸粘贴位置（建议：桌面中央、入口处）
- 确定打卡点位置（建议：门口/装饰墙/显眼位置）
- 确定推荐菜品和奖励套餐

**Step 4：物料制作与安装**
- 制作NFC贴纸（尺寸、数量根据门店桌位确定）
- 制作打卡点标识牌
- 制作活动海报（60*90cm，摆放于入口处）
- 运营人员上门安装贴纸和物料

**Step 5：人员培训**
- 组织服务员进行活动培训（培训时长：30-60分钟）
- 发放《服务员操作手册》
- 建立商家企微群，配置专属客服

**Step 6：系统配置**
- 在管理后台配置门店信息
- 配置奖励套餐（饮品/荤菜/甜品选项）
- 配置活动规则和时间
- 配置客服企微二维码

**Step 7：上线测试**
- 运营人员到店测试完整流程
- 测试各奖励核销是否正常
- 测试数据上报是否准确
- 确认无误后正式上线

**Step 8：正式运营**
- 活动上线，门店开始执行
- 每周查看数据报告
- 每月与运营经理复盘优化

5. 选择参与门店（如有多门店，需逐一配置）

**配置闯关任务**
1. 进入「任务配置」标签
2. 第一关配置：
   - 任务名称：进门礼
   - 任务类型：NFC触碰 + 企微关注
   - 关联企微客服：选择本店的企微账号
   - 奖励配置：选择饮品SKU，设置库存数量
3. 第二关配置：
   - 任务名称：打卡礼
   - 任务类型：拍照打卡 + 点评打卡
   - 打卡点配置：上传打卡点图片，设置位置描述
   - 奖励配置：选择荤菜SKU，设置库存数量
4. 第三关配置：
   - 任务名称：裂变礼
   - 任务类型：社交平台发布
   - 平台配置：抖音/小红书/大众点评（可多选）
   - 奖励配置：选择甜品SKU，设置库存数量
   - 抽奖配置：开启霸王餐抽奖，设置抽奖时间

**配置物料信息**
1. 上传门店logo
2. 上传打卡点实拍图
3. 配置推荐菜品图片和描述
4. 设置AI文案模板（可选）

**保存并提交审核**
1. 检查所有配置项
2. 点击「保存草稿」或「提交审核」
3. 等待运营人员审核（1个工作日内）

### 审核操作步骤

**商家自检清单**
- [ ] 活动名称和规则描述无误
- [ ] 所有奖励SKU已正确配置（名称、价格、图片）
- [ ] 打卡点位置描述准确，图片清晰
- [ ] 企微二维码已更新为最新
- [ ] 活动有效期设置正确

**提交审核**
1. 在管理后台点击「提交审核」
2. 填写审核备注（如有特殊说明）
3. 等待平台运营审核

**审核结果处理**
- **审核通过**：收到短信/企微通知，活动自动生效
- **审核驳回**：查看驳回原因，修改后重新提交
  - 常见驳回原因：奖励图片不清晰、规则描述有歧义、SKU价格与门店不符
  - 修改方式：根据审核意见调整对应配置项，重新提交

### 核销操作步骤

**核销准备**
1. 商家管理员在管理后台开通核销权限
2. 服务员下载「核销助手」APP或使用微信小程序「NFC核销」
3. 服务员登录核销账号（手机号+验证码）

**奖励核销流程**
1. 顾客出示企微里的奖励券码
2. 服务员打开核销工具，点击「扫码核销」
3. 扫描顾客券码（或手动输入券码）
4. 系统显示奖励信息（奖励名称、有效期、使用条件）
5. 确认无误后点击「确认核销」
6. 核销成功，系统记录核销时间和操作员

**霸王餐中奖核销**
1. 活动结束后，系统公布中奖名单
2. 中奖用户凭手机号到店核销
3. 服务员在核销工具中点击「中奖兑奖」
4. 输入中奖手机号查询
5. 确认中奖信息后，点击「确认兑奖」
6. 系统记录兑奖信息，完成核销

**核销异常处理**
- **券码已使用**：系统提示「该券码已核销」，无法重复使用
- **券码已过期**：系统提示「已超过有效期」，建议顾客联系客服
- **券码不存在**：核对是否为正确券码，如仍有问题联系平台客服

### 常见问题FAQ（商家端）

**Q：NFC贴纸掉了怎么办？**
A：联系平台客服申请补发，商家自行粘贴即可（粘贴位置参考安装指南）

**Q：库存用完了可以临时加量吗？**
A：可以，在管理后台「奖励配置」中修改库存数量，实时生效

**Q：顾客说奖励找不到/没到账怎么处理？**
A：让顾客截屏发给您，登录管理后台「奖励管理」查看状态，如异常可手动补发

**Q：可以同时做多场活动吗？**
A：可以，但建议错峰开展，避免用户混淆；不同活动可设置不同奖励内容

**Q：不想做了怎么退出活动？**
A：提前30天联系运营经理申请终止合同，终止后所有物料下架，活动页面关闭

### 风险提示

1. **活动合规性**：确保活动内容不违反《广告法》及平台相关规定
2. **奖励真实性**：奖励需与承诺一致，不得设置虚假奖励或隐形条款
3. **用户隐私保护**：收集用户信息需获得用户同意，严格遵守《个人信息保护法》
4. **刷单风控**：系统会监测异常参与行为，如发现刷单可联系平台处理
5. **节假日调整**：重大节假日需提前调整活动规则或库存配置
